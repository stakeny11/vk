# Деплой бота на Railway + локальный ПК-агент

Архитектура:

```
   Telegram  ◄──────►  Railway: tg_bot.py  ◄── HTTP ──►  ПК: pc_agent.py
                       (всегда онлайн)                   (когда включён)
                                                              │
                                                              ▼
                                                   vk_clips_browser_queue.py
                                                       (Edge + Playwright)
```

- **Бот на Railway** всегда онлайн, отвечает на команды Telegram, держит очередь задач.
- **ПК-агент** опрашивает Railway каждые 4 секунды. Если есть задача — забирает её и запускает локальный uploader.
- Если ПК выключен — задача висит в очереди. Включишь ПК → сразу подхватится.

---

## Шаг 1. Сгенерируй секретный токен

В терминале:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(40))"
```

Получишь что-то вроде `gP3...XYZ`. Сохрани, понадобится в двух местах.

---

## Шаг 2. Деплой на Railway

### 2.1. Создай новый проект

1. Зайди на https://railway.app и залогинься.
2. **New Project → Deploy from GitHub repo** (или **Empty Project + Upload**).
3. Выбери папку `zaliver/railway/` (только её, не весь zaliver).

### 2.2. Структура которая улетит на Railway

```
railway/
├── tg_bot.py
├── requirements.txt
├── Procfile
└── railway.json
```

### 2.3. Поставь Environment Variables

В разделе **Variables** добавь:

| Имя | Значение |
|-----|----------|
| `BOT_TOKEN` | Твой токен от @BotFather |
| `PC_AGENT_TOKEN` | Тот же секрет что сгенерил в Шаге 1 |
| `OWNER_USER_ID` | Твой Telegram user_id (например `872428450`) |
| `ACCESS_CODE` | Кодовое слово для входа в бота (например `КириллШaрапов`) |
| `PC_OFFLINE_AFTER_SEC` | `20` (опционально) |

`PORT` Railway проставит сам.

### 2.4. Включи публичный домен

**Settings → Networking → Generate Domain**.
Получишь URL типа `https://your-app.up.railway.app`.

Проверь: открой `https://your-app.up.railway.app/health` — должно вернуть JSON.

---

## Шаг 3. Настрой ПК-агент

### 3.1. Создай `pc_agent.env`

В папке `zaliver/` (рядом с `pc_agent.py`) создай файл `pc_agent.env`:

```
RAILWAY_URL=https://your-app.up.railway.app
PC_AGENT_TOKEN=тот-же-секрет-из-Railway
```

### 3.2. Запусти агент

Двойным кликом по `run_pc_agent.bat` или из консоли:

```powershell
cd "c:\Users\user\Desktop\devinai\zaliver"
python pc_agent.py
```

Должно вывести:

```
============================================================
PC AGENT для VK Clips Uploader
  Railway: https://your-app.up.railway.app
  ПК:      DESKTOP-XXX
  Скрипт:  vk_clips_browser_queue.py
============================================================
[12:34:56] Стартую long-poll к https://...
```

Если видишь `connect error: ...` — значит RAILWAY_URL или PC_AGENT_TOKEN неверный.

---

## Шаг 4. Используй бота

В Telegram → `/start` твоему боту → введи `ACCESS_CODE`.

После авторизации появится меню:

| Кнопка | Действие |
|--------|----------|
| ▶️ Запустить заливку | ставит задачу `start_vk` в очередь |
| ⏹ Стоп | ставит задачу остановки |
| 📊 Статус | показывает онлайн ли ПК + очередь + последняя строка лога |
| 📜 Лог | последние 80 строк |
| 👁 Вкл логи | каждая строка stdout будет приходить как сообщение в TG |
| 🙈 Выкл логи | отписаться от потока логов |
| 🧹 Очистить очередь | сбросить накопленные задачи |

### Команды текстом
- `/run` — старт
- `/stop` — остановка
- `/status`
- `/log`
- `/watch_on`, `/watch_off`
- `/grant <user_id>` (только владельцу) — выдать доступ другому пользователю

---

## Шаг 5. Автозапуск ПК-агента (опционально)

Чтобы агент стартовал автоматически при включении Windows:

1. `Win+R` → `shell:startup` → откроется папка автозагрузки.
2. Скопируй туда ярлык на `run_pc_agent.bat`.

Теперь после включения ПК агент сам подключится к Railway, и бот сразу станет «🟢 онлайн».

---

## Что делать если ПК офлайн

Бот в Telegram спокойно ответит, поставит задачу в очередь и напишет:

> 🔌 Задача в очереди. ПК сейчас офлайн — выполнится как только включится.

Когда ты включишь ПК и `pc_agent.py` стартанёт, он подхватит задачу автоматически.

---

## Безопасность

- **`PC_AGENT_TOKEN`** — никому не показывай. Это «ключ» от твоего ПК. Любой кто знает токен может ставить тебе задачи через `/pc/poll`.
- **`ACCESS_CODE`** — защита бота от чужих в Telegram. Любой кто его знает получит доступ.
- Если случайно слил — на Railway смени `PC_AGENT_TOKEN` (Variables) и в `pc_agent.env` на ПК поставь то же новое значение.

## Troubleshooting

**ПК всегда показан 🔴 офлайн**
- Проверь в логе агента нет ли `connect error`.
- Открой `https://your-app.up.railway.app/health` в браузере — отвечает?
- В `pc_agent.env` URL без `/` в конце.

**Задачи не доходят**
- В логах агента после `poll http 401` → токены не совпадают.
- Сверь PC_AGENT_TOKEN в Railway Variables и в `pc_agent.env`.

**Бот не отвечает в TG**
- Проверь BOT_TOKEN в Railway Variables.
- В логах Railway-приложения должно быть `📡 Стартую Telegram long-polling`.
- Убедись что бот не заблокирован тобой в @BotFather.

**Скрипт запускается, но падает**
- Это уже логика `vk_clips_browser_queue.py`. Включи 👁 логи в боте — увидишь точную ошибку.
- Скрин падения лежит на ПК в `zaliver/debug_screens/fail_<group>_<ts>.png`.
